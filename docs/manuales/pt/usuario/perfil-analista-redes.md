## Seu perfil: analista de redes

O AuditNet é uma plataforma web para auditar configurações de equipamentos de rede (roteadores e switches Cisco
IOS/IOS-XE). Cada organização registra seus dispositivos, define como cada tipo de equipamento deve estar configurado
(baselines e regras), importa as configurações reais e as audita. O resultado são achados com evidência, alertas para
o que é mais grave e relatórios para a gestão.

Como **analista de redes** você conduz a operação técnica do dia a dia na sua organização.

| Você pode | Onde |
|---|---|
| Importar a configuração (running-config) de um equipamento | Auditorias |
| Executar auditorias e revisar o resultado regra por regra | Auditorias |
| Comparar uma auditoria com a anterior do mesmo equipamento | Histórico de auditorias |
| Atualizar o acompanhamento dos achados (em revisão, resolvido, risco aceito) | Achados |
| Encaminhar ou devolver alertas críticos | Alertas críticos |
| Gerar relatórios e baixá-los em PDF ou CSV | Relatórios |
| Consultar dispositivos, baselines e regras | Dispositivos, Baselines, Regras |

O ciclo habitual é: **importar → auditar → revisar achados → corrigir no equipamento → importar e auditar de novo**.
Quando uma regra que falhava é cumprida em uma nova auditoria, o AuditNet marca sozinho o achado anterior como
resolvido e fecha o seu alerta.
