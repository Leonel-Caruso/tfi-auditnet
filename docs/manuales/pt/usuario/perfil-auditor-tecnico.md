## Seu perfil: auditor técnico

O AuditNet é uma plataforma web para auditar configurações de equipamentos de rede (roteadores e switches Cisco
IOS/IOS-XE). Cada organização registra seus dispositivos, define como cada tipo de equipamento deve estar configurado
(baselines e regras), importa as configurações reais e as audita. O resultado são achados com evidência, alertas para
o que é mais grave e relatórios para a gestão.

Como **auditor técnico** você define **o que é controlado**: as baselines e suas regras são a referência contra a qual
cada configuração é avaliada.

| Você pode | Onde |
|---|---|
| Criar baselines por tipo de dispositivo, gerar novas versões e ativá-las ou desativá-las | Baselines |
| Criar, editar, ativar e desativar regras | Regras |
| Importar configurações e executar auditorias | Auditorias |
| Revisar a evidência e atualizar o acompanhamento dos achados | Achados |
| Gerar relatórios e baixá-los em PDF ou CSV | Relatórios |
| Consultar dispositivos, histórico e alertas | Dispositivos, Histórico, Alertas críticos |

> **Nota:** os alertas críticos são encaminhados pelo analista e pelo responsável pela gestão de TI; o seu perfil os
> consulta. Você também não recebe avisos de auditoria por e-mail.
