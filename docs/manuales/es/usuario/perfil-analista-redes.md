## Tu perfil: analista de redes

AuditNet es una plataforma web para auditar configuraciones de equipos de red (routers y switches Cisco IOS/IOS-XE).
Cada organización registra sus dispositivos, define cómo tiene que estar configurado cada tipo de equipo (baselines y
reglas), importa las configuraciones reales y las audita. El resultado son hallazgos con evidencia, alertas para lo más
grave y reportes para la gestión.

Como **analista de redes** sos quien lleva la operación técnica del día a día en tu organización.

| Podés | Dónde |
|---|---|
| Importar la configuración (running-config) de un equipo | Auditorías |
| Ejecutar auditorías y revisar el resultado regla por regla | Auditorías |
| Comparar una auditoría con la anterior del mismo equipo | Historial de auditorías |
| Actualizar el seguimiento de los hallazgos (en revisión, resuelto, riesgo aceptado) | Hallazgos |
| Derivar o devolver alertas críticas | Alertas críticas |
| Generar reportes y descargarlos en PDF o CSV | Reportes |
| Consultar dispositivos, baselines y reglas | Dispositivos, Baselines, Reglas |

El ciclo habitual es: **importar → auditar → revisar hallazgos → corregir en el equipo → volver a importar y
auditar**. Cuando una regla que fallaba se cumple en una auditoría nueva, AuditNet marca solo el hallazgo anterior como
resuelto y cierra su alerta.
