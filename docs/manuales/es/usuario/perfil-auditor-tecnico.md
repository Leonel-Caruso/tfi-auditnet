## Tu perfil: auditor técnico

AuditNet es una plataforma web para auditar configuraciones de equipos de red (routers y switches Cisco IOS/IOS-XE).
Cada organización registra sus dispositivos, define cómo tiene que estar configurado cada tipo de equipo (baselines y
reglas), importa las configuraciones reales y las audita. El resultado son hallazgos con evidencia, alertas para lo más
grave y reportes para la gestión.

Como **auditor técnico** definís **qué se controla**: las baselines y sus reglas son la referencia contra la que se
evalúa cada configuración.

| Podés | Dónde |
|---|---|
| Crear baselines por tipo de dispositivo, generar versiones nuevas y activarlas o desactivarlas | Baselines |
| Crear, modificar, activar y desactivar reglas | Reglas |
| Importar configuraciones y ejecutar auditorías | Auditorías |
| Revisar la evidencia y actualizar el seguimiento de los hallazgos | Hallazgos |
| Generar reportes y descargarlos en PDF o CSV | Reportes |
| Consultar dispositivos, historial y alertas | Dispositivos, Historial, Alertas críticas |

> **Nota:** las alertas críticas las derivan el analista y el responsable de gestión IT; tu perfil las consulta. Tampoco
> recibís avisos de auditoría por correo.
