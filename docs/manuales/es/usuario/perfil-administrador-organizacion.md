## Tu perfil: administrador de organización

AuditNet es una plataforma web para auditar configuraciones de equipos de red (routers y switches Cisco IOS/IOS-XE).
Cada organización registra sus dispositivos, define cómo tiene que estar configurado cada tipo de equipo (baselines y
reglas), importa las configuraciones reales y las audita. El resultado son hallazgos con evidencia, alertas para lo más
grave y reportes para la gestión.

Como **administrador de organización** gestionás todo lo de **tu organización**: su gente, sus sedes, su inventario y
su plan. No ves datos de otras organizaciones.

| Podés | Dónde |
|---|---|
| Registrar, modificar y deshabilitar las sedes de tu organización | Organizaciones y sedes |
| Definir los plazos de revisión (cuándo vence un hallazgo y cada cuánto se re-audita) | Organizaciones y sedes |
| Dar de alta usuarios con perfiles de operación (analista, auditor, responsable de gestión IT), modificarlos, deshabilitarlos, restablecer su contraseña y desbloquearlos | Usuarios |
| Consultar el plan y pedir un cambio | Mi plan |
| Registrar, modificar y dar de baja dispositivos | Dispositivos |
| Consultar baselines, reglas, auditorías, hallazgos, alertas y reportes | Cada pantalla, en modo consulta |

> **Nota:** importar configuraciones, ejecutar auditorías o cambiar el estado de un hallazgo son tareas de los
> perfiles de operación. Si además tenés que hacerlas, pedí al administrador del sistema que te agregue ese perfil: un
> usuario puede tener varios.
