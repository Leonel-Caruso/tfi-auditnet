## Problemas frecuentes

| Situación | Qué hacer |
|---|---|
| *Usuario o contraseña incorrectos* | Revisá mayúsculas y que no tengas el bloqueo de mayúsculas. Si no la recordás, usá **¿Olvidaste tu contraseña?** |
| *La cuenta está bloqueada* | Después de 5 intentos fallidos se bloquea 15 minutos. Esperá, recuperá la contraseña o pedile a un administrador que la desbloquee. |
| *Tu sesión terminó* | Venció o un administrador cambió tu perfil, tu organización o tu contraseña. Volvé a ingresar. |
| No veo una pantalla o un botón | Tu perfil no tiene ese permiso. La matriz de permisos está en *Usuarios* (para administradores) y el primer capítulo de este manual resume lo que hace tu perfil. |
| *No existe una baseline activa aplicable* | La organización no tiene una baseline activa para el tipo de ese dispositivo. La crea o activa el auditor técnico. |
| No puedo sumar dispositivos o usuarios | Se llegó al límite del plan o venció la prueba del plan Piloto. El administrador de la organización pide un cambio en *Mi plan*. |
| No llegan los correos | Revisá *Mi cuenta → Avisos por correo* y la carpeta de correo no deseado. Los avisos de auditoría dependen del perfil. |
| La pantalla se ve en otro idioma o tema | Cambialos en el menú del usuario; quedan guardados en tu cuenta. |
| El manual no se descarga | Probá desde el menú del usuario → *Manual*. Si sigue fallando, avisá al administrador del sistema. |
