## Tu perfil: administrador del sistema

AuditNet es una plataforma web para auditar configuraciones de equipos de red (routers y switches Cisco IOS/IOS-XE).
Cada organización cliente registra sus dispositivos, define cómo tiene que estar configurado cada tipo de equipo
(baselines y reglas), importa las configuraciones reales y las audita. El resultado son hallazgos con evidencia,
alertas para lo más grave y reportes para la gestión.

Como **administrador del sistema** tenés el alcance más amplio: ves y operás todas las organizaciones.

| Podés | Dónde |
|---|---|
| Registrar organizaciones cliente, asignarles un plan y gestionar sus sedes | Organizaciones y sedes |
| Crear usuarios de cualquier perfil, cambiarlos, deshabilitarlos, restablecer contraseñas y desbloquear cuentas | Usuarios |
| Aprobar o rechazar pedidos de cambio de plan y ajustar los precios de referencia | Planes y solicitudes |
| Registrar tipos de dispositivo y gestionar el inventario de cualquier organización | Dispositivos |
| Definir baselines y reglas, importar configuraciones y ejecutar auditorías | Baselines, Reglas, Auditorías |
| Atender hallazgos y alertas y generar reportes | Hallazgos, Alertas críticas, Reportes |
| Consultar las bitácoras y la salud de la plataforma, ejecutar la revisión periódica y generar respaldos | Bitácoras, Panel de administración |

> **Importante:** los cinco perfiles son fijos y sus permisos los aplica el servidor. Aunque alguien conozca la
> dirección de una pantalla, si su perfil no tiene permiso la operación se rechaza.
