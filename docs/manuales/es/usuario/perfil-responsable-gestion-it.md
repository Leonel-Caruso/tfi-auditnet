## Tu perfil: responsable de gestión IT

AuditNet es una plataforma web para auditar configuraciones de equipos de red (routers y switches Cisco IOS/IOS-XE).
Cada organización registra sus dispositivos, define cómo tiene que estar configurado cada tipo de equipo (baselines y
reglas), importa las configuraciones reales y las audita. El resultado son hallazgos con evidencia, alertas para lo más
grave y reportes para la gestión.

Como **responsable de gestión IT** seguís el estado de tu organización y decidís prioridades: no hace falta que operes
los equipos.

| Podés | Dónde |
|---|---|
| Ver el nivel de riesgo, los indicadores y la evolución semanal | Tablero de control, Estado del cliente |
| Derivar alertas críticas a un perfil técnico o devolverlas | Alertas críticas |
| Consultar hallazgos, historial, dispositivos y reglas | Cada pantalla, en modo consulta |
| Consultar y descargar reportes en PDF o CSV | Reportes |
| Consultar el plan y las solicitudes de cambio | Mi plan |
| Recibir por correo las alertas, los vencimientos y el resumen mensual | Mi cuenta |
