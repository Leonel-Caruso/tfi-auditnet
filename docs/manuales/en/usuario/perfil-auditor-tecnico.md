## Your profile: technical auditor

AuditNet is a web platform for auditing the configuration of network devices (Cisco IOS/IOS-XE routers and
switches). Each organization registers its devices, defines how each device type must be configured (baselines and
rules), imports the actual configurations and audits them. The result is findings with evidence, alerts for the most
serious ones and reports for management.

As **technical auditor** you define **what is checked**: baselines and their rules are the reference every
configuration is evaluated against.

| You can | Where |
|---|---|
| Create baselines per device type, generate new versions and activate or deactivate them | Baselines |
| Create, modify, activate and deactivate rules | Rules |
| Import configurations and run audits | Audits |
| Review the evidence and update the tracking of findings | Findings |
| Generate reports and download them as PDF or CSV | Reports |
| View devices, history and alerts | Devices, Audit history, Critical alerts |

> **Note:** critical alerts are assigned by the network analyst and the IT management lead; your profile can view
> them. You do not receive audit notices by email either.
