## Your profile: system administrator

AuditNet is a web platform for auditing the configuration of network devices (Cisco IOS/IOS-XE routers and
switches). Each organization registers its devices, defines how each device type must be configured (baselines and
rules), imports the actual configurations and audits them. The result is findings with evidence, alerts for the most
serious ones and reports for management.

As **system administrator** you have the widest scope: you see and operate every organization.

| You can | Where |
|---|---|
| Register client organizations, assign them a plan and manage their sites | Organizations and sites |
| Create users of any profile, change them, disable them, reset passwords and unlock accounts | Users |
| Approve or reject plan change requests and adjust reference prices | Plans and requests |
| Register device types and manage the inventory of any organization | Devices |
| Define baselines and rules, import configurations and run audits | Baselines, Rules, Audits |
| Work on findings and alerts and generate reports | Findings, Critical alerts, Reports |
| Review the logs and platform health, run the periodic review and create backups | Logs, Administration panel |

> **Important:** the five profiles are fixed and their permissions are enforced by the server. Even if someone knows
> the address of a screen, the operation is rejected when their profile is not allowed to do it.
