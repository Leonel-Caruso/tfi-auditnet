## Your profile: network analyst

AuditNet is a web platform for auditing the configuration of network devices (Cisco IOS/IOS-XE routers and
switches). Each organization registers its devices, defines how each device type must be configured (baselines and
rules), imports the actual configurations and audits them. The result is findings with evidence, alerts for the most
serious ones and reports for management.

As **network analyst** you run the day-to-day technical operation of your organization.

| You can | Where |
|---|---|
| Import a device's configuration (running-config) | Audits |
| Run audits and check the result rule by rule | Audits |
| Compare an audit with the previous one of the same device | Audit history |
| Update the tracking of findings (in review, resolved, risk accepted) | Findings |
| Assign or return critical alerts | Critical alerts |
| Generate reports and download them as PDF or CSV | Reports |
| View devices, baselines and rules | Devices, Baselines, Rules |

The usual cycle is: **import → audit → review findings → fix the device → import and audit again**. When a rule that
was failing is met in a new audit, AuditNet marks the previous finding as resolved and closes its alert.
